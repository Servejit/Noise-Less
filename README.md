# Noise Less 🎙️\n\nA simple Streamlit app to reduce background noise in recorded video audio. Built with Python and FFmpeg.\n\n## Features\n- Upload MP4, MOV, AVI, MKV, or WEBM\n- Adjustable noise reduction strength\n- Preview cleaned audio and video\n- Download a cleaned MP4\n- Video stream is copied without video re-encoding when supported\n\n## Run locally\nInstall FFmpeg, then run:\n\n```bash\npip install -r requirements.txt\nstreamlit run app.py\n```\n\nOn Streamlit Community Cloud, set the main file to `app.py`. The `packages.txt` file installs FFmpeg.\n\n**Limitations:** This initial version performs general noise reduction. It does not yet guarantee source separation of your voice from overlapping speech, TV music, or other distinct sounds.\n
